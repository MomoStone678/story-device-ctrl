# 戏控台 · Story Device Ctrl

SillyTavern 扩展（对外中文名 **戏控台**）。用网页蓝牙按 `[CTRL:…]` 驱动外接设备。

## 用酒馆「安装扩展」链接时

请粘贴**本仓库地址**。默认分支 **只含扩展**，不会把蓝牙标定工具装进酒馆。

电脑端档案标定请用**独立仓库「信道台」**（不是本仓的分支，也**不要**拷进 `third-party`）：

https://github.com/MomoStone678/ble-channel-lab

## 安装

1. 扩展 → 安装扩展 → 粘贴本仓 GitHub 链接  
2. 或下载 Release 的 `*-extension.zip` 解压到 `third-party/story-device-ctrl/`  
3. Ctrl+F5，启用「戏控台」  
4. 在电脑用信道台标定并导出 JSON → 本扩展导入 → 连接蓝牙  

更多说明见信道台仓库 README，以及本扩展面板内提示。
